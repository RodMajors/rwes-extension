# 【RodMajors】魔兽世界常用网站中文用户体验增强 (RWES)

一款面向国服玩家的油猴脚本:自动为 Wowhead、Warcraft Logs(WCL)、Raider.io、QE Live、Archon、Raidbots 等十余个魔兽世界常用网站**去广告、自动跳转简体中文、汉化全站英文名词**,让你浏览外文站点如同使用国服客户端一般自然。

---

## 主要功能

### 1. 一键汉化 · 全站英文名词自动翻译

不同于同类脚本把数据写死在脚本里,本脚本采用**服务端词典 + 本地缓存**架构:

- **覆盖全面**:词典提取自魔兽世界官方客户端数据,包含全部 17.5 万+物品、41 万+法术名,以及 NPC、地图、副本、首领、大秘境词缀、职业专精、种族、盟约、坐骑、战场、宠物技能、英雄天赋(树与节点)、制造属性、场景战役等 **40+ 类游戏专有名词**,覆盖全部资料片与怀旧服内容;
- **自动更新**:词典随魔兽版本更新而更新,脚本会自动检测新版本并**后台静默增量同步**(通常每次仅下载有变化的表,几秒完成;首次全量约 12MB);
- **离线可用**:词典缓存在浏览器 IndexedDB 中,同步完成后断网也能翻译;
- **智能匹配**:支持三种翻译方式——
    - **ID 精确翻译**:页面上的 Wowhead 链接、`data-wowhead` 属性直接按物品/法术 ID 查表,绝不出错;
    - **全名精确匹配**:纯文本里的英文名词(如装备名、专精名)按整名精确匹配,不破坏句子;
    - **组合与规则**:自动处理"专精+职业"组合词(如 _Demonology Warlock_ → 恶魔学识术士)、括号后缀(_Ruby Whelp Shell (Crit)_ → 红玉雏龙蛋壳(暴击))、常见前缀(_WoW version 12.1.0_ → 魔兽世界版本 12.1.0)与手工维护的站点 UI 词条(如 _Timewalking_ → 时光漫游)。

### 2. 鼠标提示强制简体中文

所有站点上由 Wowhead 控件渲染的物品/法术鼠标提示,一律强制显示**简体中文**名称与说明(自动改写 `whTooltips` 与页面 `Locale` 配置)。

### 3. Wowhead 全站汉化

- 自动将 Wowhead 页面(含所有语言路径)重定向到 `/cn/` 简体中文版本;
- 全站范围内的 Wowhead 外链统一改写为简中镜像地址;
- 可选:测试服链接(ptr/beta)强制改到正式服简中(谨慎开启)。

### 4. Warcraft Logs(WCL)自动跳转

自动跳转 `cn.warcraftlogs.com` 中文子域名(保留 classic/season 等特殊版本子域名,不乱跳)。

### 5. 去广告 + 版面优化

针对 Wowhead、WCL、Raider.io 等站点的广告位进行 CSS 屏蔽与 DOM 清理,并优化 Wowhead 的分栏布局,阅读更清爽。

## 使用与配置

安装后在 Tampermonkey 工具栏菜单(点击扩展图标 → 菜单)中可开关:

- ✅/❌ **Wowhead 自动跳转简中** —— 开关 Wowhead 页面重定向;
- ✅/❌ **WCL 自动跳转 cn** —— 开关 WCL 子域名跳转;
- ✅/❌ **测试服链接强制改正式服简中** —— 默认关闭;
- ✅/❌ **自动翻译英文名词** —— 总开关,默认开启;
- **清空词典缓存** —— 词典同步异常或想强制全量重下时使用。

首次访问任一支持站点时,词典在后台静默下载,**不影响页面浏览**;下载完成后自动生效。

## 常见问题

**Q:为什么有些词还是英文?**
A:新数据随魔兽版本更新,请先刷新页面等待词典增量同步;若个别名词长期缺失,欢迎在反馈区留言(附上页面地址和英文原文)。

**Q:会不会误翻普通英文单词?**
A:文本翻译采用"整名精确匹配",且词典构建时已过滤 _shadow、mail、gold_ 等 5000 个常见英文单词,另有品牌名黑名单(如 Archon 站点自身的 "Archon"),大幅降低误翻概率。发现误翻欢迎反馈。

**Q:脚本更新后为什么功能没变化?**
A:词典数据会自动更新,但**脚本代码更新需要手动重新安装**(Tampermonkey 仪表盘 → 更新脚本)。

**Q:隐私安全吗?**
A:脚本仅在启动时向 `wowdata.rodmajors.com` 请求词典清单与文件,不上传任何个人信息;其余请求仅发生于你所访问的站点本身。
